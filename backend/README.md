# Gimbie Adventist General Hospital - Backend API

## Hospital Management System with Digital + Paper Workflow

### Features
- Patient Registration with QR Codes
- Electronic Medical Records
- Consultation Management
- Laboratory Request & Results
- Prescription & Pharmacy Management
- Billing & Payments
- Appointment Scheduling
- Staff Management
- Printable Documents (PDF)
- Audit Logging
- Role-based Access Control

### Technology Stack
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication
- PDFKit for document generation
- QRCode for patient identification
