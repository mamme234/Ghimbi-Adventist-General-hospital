# 🏥 Gimbie Adventist General Hospital Management System

A comprehensive digital hospital management system with a modern, glassmorphism design that supports both paper and digital workflows.

## 🌟 Features

### Patient Management
- ✅ Patient registration with unique ID and QR Code
- ✅ Patient search and lookup
- ✅ Patient card printing
- ✅ Medical records management
- ✅ Appointment scheduling

### Clinical Workflow
- ✅ Consultation sheets with digital signature
- ✅ Laboratory request and results
- ✅ Digital prescriptions with QR codes
- ✅ Pharmacy dispensing with inventory management
- ✅ Billing and payment processing

### Staff Portals
- ✅ Admin Dashboard - Full system control
- ✅ Doctor Portal - Consultations, prescriptions, lab requests
- ✅ Nurse Portal - Patient monitoring, admissions
- ✅ Reception Portal - Patient registration, appointments
- ✅ Laboratory Portal - Test requests, results entry
- ✅ Pharmacy Portal - Dispensing, inventory
- ✅ Finance Portal - Billing, payments

### Modern Features
- ✅ Glassmorphism + Neumorphism UI design
- ✅ Progressive Web App (PWA)
- ✅ QR Code generation for patient identification
- ✅ PDF document generation
- ✅ AI Assistant for patient support
- ✅ Multi-language support
- ✅ Responsive mobile-first design
- ✅ Offline support

## 🚀 Technology Stack

### Frontend
- HTML5
- CSS3 (Glassmorphism, Neumorphism)
- JavaScript (ES2027)
- Progressive Web App (PWA)

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication

### Deployment
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
